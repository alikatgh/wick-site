What you get

Wick is the language; Lantern supplies the window, renderer, audio, input and game loop. The desktop host also runs Lua games, and C/C++ games can use the C ABI.

2D & 3D
Depth-tested meshes, per-vertex lighting and fog, then sprites and text on the same frame.
Assets
OBJ meshes, BMP textures with magenta transparency, and WAV sound.
Interaction
Keyboard and gamepad input, single-point touch or mouse input, and per-name saves.
Development
Reload on save, in-engine diagnostics, fixed-timestep runs and framebuffer screenshots.

Download for macOS Apple Silicon

Built on macOS 15.6. Ad-hoc signed; not Apple notarized. There is no separate Wick installer.

Extract the archive and open a terminal in the extracted folder:

./lantern games/bitlab

You should see two registers and an operation selector. Use the arrow keys to change a register and Z to cycle ADD, AND and XOR.

Build from source

The desktop build needs a C++20 compiler, CMake 3.20 or later, SDL2, Lua and pkg-config. On macOS, install the dependencies with Homebrew after installing the Xcode Command Line Tools:

brew install sdl2 lua cmake pkg-config

Then get the source for this release and build it:

git clone --branch v0.8.0 https://github.com/alikatgh/lantern.git
cd lantern
cmake -S . -B build
cmake --build build
./build/lantern games/wicklab

On Linux, install the compiler and corresponding development packages with your distribution's package manager before the same CMake steps. The supplied binary is macOS-only; see platform status before choosing a build route.

Wick Lab demonstrates language and engine features. For a new game, create a folder containing main.wick and pass that folder to the host. The first-program guide includes a complete example.

Bit Lab
Registers, bit operations, flags and program-counter wrapping.
./build/lantern games/bitlab

Bit Lab is a language workbench for processor-building ideas. It is not a complete Intel 8080 emulator or the finished game. Read bits, bytes and words for the language operations behind it.

Package a game

A game folder contains main.wick and any assets it loads. Paths are relative to the game folder; nested paths such as assets/tiles.bmp are supported.

mygame/
  main.wick
  assets/
    tiles.bmp
    click.wav

From a source build, pack the folder into one file, then run it:

./build/lantern_pack mygame mygame.lant
./build/lantern mygame.lant

With the downloaded bundle, use ./lantern_pack and ./lantern instead. Keep the original game folder for editing.

Platforms & limits

TargetAvailable route
macOS Apple SiliconRelease binary and source build. This release was built on macOS 15.6.
Other desktop targetsSDL-based source build. No Linux, Windows or Intel Mac binary is included in this release; these targets were not verified for this website update.
iPhone / iPadNative backend in the repository. Requires an Xcode build and game bundling; this release does not supply an iOS app.

The renderer stays at 400 × 240; window size changes presentation, not render resolution. Lighting is per vertex, textures are BMP, audio is WAV, and touch is single-point. Wick has no JIT. Check language limits before choosing data structures.
