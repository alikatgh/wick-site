# Wick ブログへようこそ { #welcome-to-the-wick-blog }

*2026-07-14*

Wick は [Lantern](https://github.com/alikatgh/lantern) エンジン独自のスクリプト言語です。
午後のうちに読める約 2,000 行の C++、依存関係なし、zlib ライセンス。
このブログには、言語を変える**理由**を記録します。Go における Go ブログと同じ役割です。
公開直後の話題作りではなく、設計の記憶を恒久的に残します。

## Wick の用途 { #what-wick-is-for }

Lantern のゲームは `main.wick` を持つフォルダです（ローカル開発には `main.lua` も使えます）。
エンジンは固定の 400×240 ソフトウェアフレームバッファに対して、60 fps で `update(dt)` と
`draw()` を呼び出します。Wick は**このループのための母語**です。

- ゲーム全体を 1 つのファイルに収め、頭の中で把握できるほど小さい
- Lua で痛い思いをした種類のバグが、コンパイルを通らないほど厳密
- ストアのパッケージが、型付きの `lt.*` ネイティブ関数以外からファイルシステムや
  ネットワークにアクセスできないほど安全

汎用言語ではありません。Python や JavaScript を追いかけることはありません。
ほかの言語と同じ機能を持つことは、言語を拡張する理由に**明示的になりません**。

## 基本方針 { #the-constitution }

[台帳](../limits.md)から引用します。

> 実際のゲームコードで、その機能がないために問題が生じたことを示せて初めて、言語に採用します。

オプショナルは、空のセーブファイルが公開済みのゲームのフレームをクラッシュさせたため採用しました。
レコードは、KORA のキッチンの小物が 5 本の並列リストになったため採用しました。
文字列の添字アクセスは*採用していません*。マップのオフライン生成で、まだ無理なく対応できるからです。

機能が欲しい場合は、実際の痛い経験を持ってきてください。実際のゲーム内の箇所、失敗するパターン、
回避策との比較です。その判断をここで公開します。
