# Wick 0.2 — リリースノート { #wick-02-release-notes }

*2026-07-14*

Lantern `engine=0.7` 内の言語としての Wick に対する、初めての正式なマイナーリリースノートです。
バージョンはまだ 1.0 未満です。この番号は利用者と変更履歴のためのもので、安定性を約束するものではありません。

## 主な変更 { #highlights }

1. **レコード** — `record Name { field: type, ... }`、構築、フィールドへのアクセス、`list<record>`。
2. **ストア配信に対応するパスのサンドボックス** — 読み込みはゲームディレクトリの外に出られません。
3. **階層のある `.lant` パッケージ** — `assets/foo.bmp` を制作から実行まで扱えます。
4. **パッケージモードでのスクリーンショット出力先の制限**。
5. **KORA** が Wick の代表作として、上記の機能をすべて使用します。

## 言語 { #language }

### 追加した機能 { #added }

```wick
record Prop {
  slot: num
  x: num
  y: num
  w: num
  h: num
}

let p = Prop { slot: 0, x: 1, y: 2, w: 8, h: 8 }
p.x = p.x + 1

let props: list<Prop> = []
push(props, p)
props[0].y = 10
```

### 意図的に変更していないもの { #unchanged-deliberately }

- オプショナル、ローカル変数のみの型の絞り込み、暗黙の真偽値変換なし、型付きの `lt.*`
- クロージャ、モジュール、文字列の添字アクセス、ネストしたコンテナなし
- JIT なし

## ホストとパッケージ化 { #host-packaging }

- すべての読み込み用ネイティブ関数に `path_sandbox` を適用（Wick + Lua）
- 再帰的な `lantern_pack` と、アーカイブ形式内の階層付きの名前
- パッケージモードではスクリーンショットの書き込みを制限
- テスト: `path_sandbox_test.sh`、拡張した `wick_test.sh`、パッケージの
  同一性テスト、KORA のキッチンのスクリーンショットテスト

## 互換性 { #compatibility }

- 並列リストを使い続ける既存の Wick ゲームは、引き続き動作します。
- フラットな `.lant` パッケージは、引き続き動作します。
- パスの範囲外へのアクセスに依存したゲーム（本来ないはずのもの）は、設計上動作しなくなります。

## 制作者向けのアップグレードの注意点 { #upgrade-notes-for-authors }

1. 表のデータが 2 本を超える並列リストになったら、`record` を優先してください。
2. アセットはゲームフォルダの中に置き、相対パスだけを使ってください。
3. CI で KORA のシーンを指定する場合、`KORA_SCENE=3` はタイトルとプロローグもスキップします。
4. [レコードの採用](2026-07-14-admitting-records.md)と
   [ストアの安全性](2026-07-14-store-safety.md)を参照してください。
