## 言語の変更を提案するには { #how-to-propose-a-language-change }

1. 公開済み、または開発中の Lantern のゲームで、**問題になっているコード**を示してください。
2. 事前処理による回避策（オフライン生成、並列リストなど）が、もはや無理のない方法ではないことを示してください。
3. 困りごとを解消する最小限の機能を提案してください。「X と同じ機能が欲しい」ではありません。
4. 採用されたら、**言語、テスト、ドキュメント、このブログ**を 1 つの変更として反映してください。

手順はこれだけです。ロードマップを決める委員会はありません。
