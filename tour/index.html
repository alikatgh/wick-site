Wick 0.3 · Lantern 0.8.0 · Open source

Wick in five minutes.

A small, statically typed language for game logic. A small engine to run it. One main.wick file to start.

Wick checks types and engine calls when your game loads. Lantern provides the 400 × 240 renderer, input, sound and game loop.

01 / The reason

Make missing values explicit.

A saved score can be missing. The saved text can also fail to parse. Wick gives both operations an optional result, so a number cannot quietly become nil.

The first ?? handles a missing save. The second handles text that is not a number. best is a num in either case.

Why not just use Lua?

You can: Lantern also runs Lua, with the same engine API. Wick adds static types, explicit optionals, boolean conditions, and checks for engine argument types and counts. Choose it when those constraints help you write a small game.

Lua remains the more flexible choice when you need features Wick does not have, such as closures, first-class functions or multiple return values. Wick is an early language with a deliberately small feature set.

03 / Try it locally

Download, run, change.

  1. Get the engine and an example.

    Download Lantern for macOS Apple Silicon. Extract it and open a terminal in the extracted folder. Wick is included; there is no separate installer.

    Built on macOS 15.6. The binary is ad-hoc signed, not notarized. Release files and checksums · Source build instructions

  2. Launch Bit Lab.

    ./lantern games/bitlab

    You should see the register workbench pictured above. Left and right select a register; up and down change its value. Press Z to cycle ADD, AND and XOR. Press Escape to quit.

  3. Make the moving square your own.

    Create the example folder:

    mkdir -p games/first-game

    Save main.wick from the example above inside that folder, then run:

    ./lantern games/first-game

    Change 40 to 80 in the file and save. The game reloads, the square restarts, and it moves twice as fast. Reloading resets game state.

    If a compiler message appears, correct the indicated line and save again. Read common errors and their fixes.

04 / Before you commit to it

Small by design. Still early.

Wick fits small games, experiments, and learning how a language and engine work together. The compiler and bytecode VM are available under the zlib license.

Language
No modules, closures, first-class functions, multiple return values or nested containers yet. Games use one main.wick file.
Engine
A fixed 400 × 240 software renderer, per-vertex lighting, BMP textures and WAV audio. No JIT.
Platforms
The current release supplies a macOS Apple Silicon binary. Other desktop targets require a source build; this release includes no Linux or Windows binary. There is no browser runtime on this page.
Example scope
Bit Lab is a register and bit-operation workbench, not a complete Intel 8080 emulator.
