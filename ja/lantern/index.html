Lantern 0.8.0 · Wick 0.3 を同梱

Lantern ゲームエンジン

固定の 400 × 240 ソフトウェアレンダラを備えた 2D/3D エンジンです。
Wick でゲームを書き、フォルダから実行し、保存すると再読み込みされます。

利用できる機能

Wick が言語を、Lantern がウィンドウ、レンダラ、音声、入力、ゲームループを提供します。デスクトップのホストは Lua のゲームも実行でき、C/C++ のゲームは C ABI を使えます。

2D と 3D
深度検査付きのメッシュ、頂点ごとの照明とフォグを描き、同じフレームにスプライトとテキストを重ねます。
アセット
OBJ メッシュ、マゼンタを透明にする BMP テクスチャ、WAV 音声。
操作
キーボードとゲームパッドの入力、単一点のタッチまたはマウス入力、名前別のセーブ。
開発
保存時の再読み込み、エンジン内の診断表示、固定タイムステップでの実行、フレームバッファのスクリーンショット。

ダウンロード

最新リリース: Lantern 0.8.0 / Wick 0.3。 すぐ実行できるバンドルは Apple Silicon 搭載の macOS 向けです。エンジン、必要なライブラリ、パッケージ作成ツール、Bit Lab が含まれます。

macOS Apple Silicon 版をダウンロード

macOS 15.6 でビルド。アドホック署名済みで、Apple の公証は受けていません。Wick の個別インストーラはありません。

アーカイブを展開し、そのフォルダでターミナルを開きます。

./lantern games/bitlab

2 つのレジスタと演算の選択欄が表示されます。矢印キーでレジスタを変更し、Z で ADD、AND、XOR を切り替えます。

全リリースファイルとチェックサム · Bit Lab パッケージ（.lant）

自分のプログラムを書く準備ができたら、同じエンジンを使ってWick のチュートリアルに進んでください。

ソースからビルド

デスクトップ版のビルドには、C++20 コンパイラ、CMake 3.20 以降、SDL2、Lua、pkg-config が必要です。macOS では、Xcode Command Line Tools をインストールしてから、Homebrew で依存関係をインストールしてください。

brew install sdl2 lua cmake pkg-config

次に、このリリースのソースを取得してビルドします。

git clone --branch v0.8.0 https://github.com/alikatgh/lantern.git
cd lantern
cmake -S . -B build
cmake --build build
./build/lantern games/wicklab

Linux では、ディストリビューションのパッケージマネージャでコンパイラと対応する開発用パッケージをインストールし、同じ CMake の手順を実行してください。提供するバイナリは macOS 用のみです。ビルド方法を選ぶ前にプラットフォームの対応状況を確認してください。

Wick Lab では言語とエンジンの機能を試せます。新しいゲームは main.wick を含むフォルダを作り、そのフォルダをホストに渡します。最初のプログラムのガイドに完全なサンプルがあります。

サンプルゲーム

これらのフォルダは、チェックアウトしたソースに含まれます。macOS のリリースバンドルには Bit Lab が含まれます。

Wick Lab
言語とエンジンのサンプル。
./build/lantern games/wicklab
Lantern Night
照明、入力、スコアの保存を備えた小さなゲーム。
./build/lantern games/showcase_wick
Bit Lab
レジスタ、ビット演算、フラグ、プログラムカウンタのラップ。
./build/lantern games/bitlab

Bit Lab は、プロセッサを作るアイデアを言語で試す作業台です。完全な Intel 8080 エミュレータや完成したゲームではありません。その基礎となる言語の操作は、ビット、バイト、ワードを参照してください。

ゲームをパッケージ化

ゲームフォルダには main.wick と、そのプログラムが読み込むアセットを置きます。パスはゲームフォルダからの相対パスで、assets/tiles.bmp のような階層のあるパスにも対応しています。

mygame/
  main.wick
  assets/
    tiles.bmp
    click.wav

ソースからビルドした場合、フォルダを 1 つのファイルにまとめて実行します。

./build/lantern_pack mygame mygame.lant
./build/lantern mygame.lant

ダウンロードしたバンドルでは、代わりに ./lantern_pack と ./lantern を使います。編集用に元のゲームフォルダを残してください。

プラットフォームと制限

対象利用できる方法
macOS Apple Siliconリリースバイナリとソースからのビルド。このリリースは macOS 15.6 でビルドしました。
その他のデスクトップ環境SDL を使ってソースからビルド。このリリースには Linux、Windows、Intel Mac のバイナリは含まれず、今回の Web サイト更新ではこれらの環境を検証していません。
iPhone / iPadリポジトリにネイティブのバックエンドがあります。Xcode でのビルドとゲームの同梱が必要です。このリリースには iOS アプリは含まれません。

レンダラは常に 400 × 240 です。ウィンドウサイズを変えても、表示方法が変わるだけで描画解像度は変わりません。照明は頂点ごと、テクスチャは BMP、音声は WAV、タッチは単一点です。Wick に JIT はありません。データ構造を選ぶ前に言語の制限を確認してください。
