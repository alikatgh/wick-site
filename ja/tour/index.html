Wick 0.3 · Lantern 0.8.0 · オープンソース

5 分で分かる Wick。

ゲームロジックのための、小さな静的型付け言語。それを動かす小さなエンジン。最初に必要なのは、1 つの main.wick ファイルです。

Wick はゲームの読み込み時に、型とエンジン呼び出しを検査します。Lantern が 400 × 240 のレンダラ、入力、音声、ゲームループを提供します。

Mac で実行する →ソースからビルド

ダウンロードできるビルドは macOS Apple Silicon 向けです。アドホック署名済みで、Apple の公証は受けていません。Wick を選ぶ前に、制限を確認してください。

01 / 理由

値がない場合を明示する。

保存したスコアが存在しないことがあります。保存したテキストの解析に失敗することもあります。Wick は両方の操作にオプショナルの結果を与えるため、数値が何も知らせず nil になることはありません。

最初の ?? は、セーブがない場合を処理します。2 つ目は、テキストが数値でない場合を処理します。どちらの場合も、best は num です。

Lua を使うだけではだめなのか？

Lua も使えます。Lantern は同じエンジン API で Lua も実行します。Wick は静的な型、明示的なオプショナル、真偽値の条件式、エンジンの引数の型と個数の検査を加えます。こうした制約が小さなゲームを書く助けになる場合に、Wick を選んでください。

クロージャ、第一級関数、複数の戻り値など、Wick にない機能が必要な場合は、Lua のほうが柔軟です。Wick はまだ初期段階の言語で、機能を意図的に小さく保っています。

03 / ローカルで試す

入手して、実行して、変更する。

  1. エンジンとサンプルを入手する。

    macOS Apple Silicon 用の Lantern をダウンロードします。展開して、そのフォルダでターミナルを開いてください。Wick は同梱されており、個別のインストーラはありません。

    macOS 15.6 でビルド。バイナリはアドホック署名済みで、公証は受けていません。リリースファイルとチェックサム · ソースからのビルド手順

  2. Bit Lab を起動する。

    ./lantern games/bitlab

    上の画像のようなレジスタの作業台が表示されます。左右キーでレジスタを選び、上下キーで値を変更します。Z で ADD、AND、XOR を切り替え、Escape で終了します。

  3. 動く正方形を自分で変えてみる。

    サンプル用のフォルダを作成します。

    mkdir -p games/first-game

    上のサンプルの main.wick をそのフォルダ内に保存し、実行します。

    ./lantern games/first-game

    ファイルの 40 を 80 に変えて保存してください。ゲームが再読み込みされ、正方形は最初から動き出し、速度が 2 倍になります。再読み込みするとゲームの状態は初期化されます。

    コンパイラのメッセージが表示されたら、示された行を修正してもう一度保存してください。よくあるエラーと修正方法を確認できます。

04 / 採用を決める前に

意図的に小さく。まだ初期段階。

Wick は小さなゲーム、実験、言語とエンジンの連携を学ぶ用途に向いています。コンパイラとバイトコード VM は zlib ライセンスで公開しています。

言語
モジュール、クロージャ、第一級関数、複数の戻り値、ネストしたコンテナはまだありません。ゲームには 1 つの main.wick ファイルを使います。
エンジン
固定の 400 × 240 ソフトウェアレンダラ、頂点ごとの照明、BMP テクスチャ、WAV 音声。JIT はありません。
プラットフォーム
現在のリリースは macOS Apple Silicon のバイナリを提供します。ほかのデスクトップ環境にはソースからのビルドが必要で、このリリースに Linux や Windows のバイナリはありません。このページにブラウザ用ランタイムはありません。
サンプルの範囲
Bit Lab はレジスタとビット演算の作業台であり、完全な Intel 8080 エミュレータではありません。
