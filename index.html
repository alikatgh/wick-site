A small language
for Lantern games.

Wick is the Lantern engine’s scripting language. It pairs a familiar, lightweight syntax with static types and explicit handling of missing values.

Write a main.wick file, run it in Lantern, and save to reload. The compiler checks your code and engine calls before the game starts.

What Wick checks

Types are inferred or written explicitly. Engine calls are checked at load time. A misspelled variable is an error, and conditions must be bool.

Values that might be absent have an optional type, such as str?. Handle the missing case before using the value.
